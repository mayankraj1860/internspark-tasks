# InternSpark - Responsive Portfolio Website (Task 1)

A modern, responsive personal portfolio web application built as part of the Frontend Development Internship at InternSpark.

🌐 Live Preview: https://mayankraj1860.github.io/internspark-tasks/task1-portfolio/

## 🚀 Features Implemented

- **Glassmorphism UI:** Modern frosted-glass visual layout with smooth styling and clean containers.
- **Light & Dark Mode:** Toggle switch with `localStorage` persistence.
- **Fully Responsive Layout:** Optimized across mobile, tablet, and desktop viewports using Bootstrap 5.
- **Interactive UI:** Smooth navigation, scroll-reveal animations, and active state tracking.
