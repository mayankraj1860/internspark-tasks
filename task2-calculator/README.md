# InternSpark - Modern GUI Calculator (Task 2)

A modern, responsive calculator web application built as part of the Frontend Development Internship at InternSpark.

🌐 **Live Preview:** [https://mayankraj1860.github.io/internspark-tasks/task2-calculator/](https://mayankraj1860.github.io/internspark-tasks/task2-calculator/)

## 🚀 Features Implemented

- **Core Arithmetic Operations:** Full support for addition, subtraction, multiplication, and division (+, -, \*, /).
- **Clean UI/UX:** Responsive layout utilizing CSS Grid for clean button symmetry across all screen displays.
- **Real-Time Preview:** Dynamic expression calculation showing live results instantly while typing.
- **Active Keyboard Support:** Full implementation of physical keyboard mapping:
  - Numbers `0` to `9` and decimal `.`.
  - Operators `+`, `-`, `*`, `/`.
  - `Enter` or `=` for calculation evaluation.
  - `Backspace` for single-digit deletion.
  - `Escape` or `Delete` to clear the screen.
- **Visual Feedback:** Custom highlight animations (`kbd-active`) triggered dynamically when buttons are pressed on the physical keyboard.
