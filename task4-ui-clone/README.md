# InternSpark - Task 4: Netflix UI Clone (UI Clone Challenge)

A fully responsive **Netflix India Clone** frontend built using HTML5, CSS3, and Vanilla JavaScript as part of the Frontend Development Internship at **InternSpark**.

🌐 **Live Demo:** [https://mayankraj1860.github.io/task4-ui-clone/](https://mayankraj1860.github.io/task4-ui-clone/)
📁 **GitHub Repository:** [https://github.com/mayankraj1860/internspark-tasks/tree/main/task4-ui-clone](https://github.com/mayankraj1860/internspark-tasks/tree/main/task4-ui-clone)

---

## 🚀 Key Features

- 🎥 **Netflix Hero Banner:** Recreated dark gradient hero overlay with email subscription input.
- 🎬 **Horizontal Scroll Slider:** Interactive "Trending Now" carousel with smooth left/right scroll controls.
- 📺 **Feature Media Sections:** TV, device, and offline download sections with embedded looping video overlays.
- ❓ **Interactive FAQ Accordion:** Expanding/collapsing Q&A items using DOM traversal.
- 🌐 **Multi-language Support:** Dynamic language switcher toggling content between **English** and **Hindi**.
- 📱 **Mobile & Tablet Responsive:** Styled with CSS media queries for seamless display across screen sizes.
- 🔝 **Sticky Navbar:** Translucent header that transitions to solid black upon page scroll.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup (`<nav>`, `<header>`, `<section>`, `<footer>`).
- **CSS3:** Flexbox, CSS Variables, Custom Media Queries, and Animations.
- **JavaScript (ES6):** Event Listeners, DOM Manipulation, and Form Validation.
